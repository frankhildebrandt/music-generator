# Historical documentation

The files in this directory describe the former Python/browser application and its installers. They are preserved as historical reference and do not describe the Tauri desktop app. The root installer scripts and Python runtime have been removed. The upstream Ubuntu installer is archived here only as historical source; do not use it for desktop bundles. These files include the upstream changes through commit 91440ee (2026-10-21). For current instructions use ../desktop.md and the repository README.
